### 🔹 Suggest.me – Social Content Sharing Platform with AI Discovery

A social platform to **recommend and share movies, series, music, and books with friends**, inspired by the simplicity of content sharing on platforms like Instagram.

🚀 **Try it here**: [Suggest.me Live Demo](https://suggest-me-prototype.netlify.app/)

- Built using **React.js, Next.js, Node.js, MongoDB**
- Users can **send recommendations directly to friends** (similar to sharing reels/posts)
- Supports **watchlists, content tracking, and personal libraries**
- Users can express **interest in recommendations**, giving feedback to the sender

📄 **Content Detail System**
- Dedicated detail pages (similar to IMDb)  
- Users can **view metadata, explore content, and post reviews**  
- Community-driven insights through shared opinions  

📊 **Social Activity & Status System**
- Users can set statuses like **Watching, Listening, Completed, Planned**
- Activity is visible to friends based on **profile privacy settings**
- Enables lightweight social tracking of what others are consuming  

🤖 **AI-Powered Discovery Engine**
- Scrapes the web to **identify where content is available**
- Provides **direct links to streaming platforms**
- One-click navigation to watch/listen on preferred platforms

### 🔹 TempChat (Open Source)

🚀 **Try it here**: [TempChat Live Demo](https://temp-chat-nqzf.onrender.com/)

A **fully ephemeral, real-time chat application** designed for temporary conversations with **zero data persistence**.

- Built using **Node.js, Express, Socket.IO, React (UMD), Tailwind CSS**
- Real-time messaging with **low-latency event-based communication**
- Supports **public & private rooms** with optional passkey protection  

🧹 **Ephemeral Architecture (Core Highlight)**
- Chat rooms **self-destruct automatically when all participants leave**
- Messages are **never stored, logged, or persisted**
- Once a message is emitted and delivered → **it no longer exists on the server**
- Designed for **privacy-first, zero-trace communication**

💬 **Advanced Messaging Experience**
- WhatsApp-style **reply system with full context preservation**
- Smart personalization (e.g., *“replied to your message”*)
- Message truncation with expand support  
- Real-time timestamps and structured message flow  

🌐 **User Experience & Features**
- Mobile-first responsive design  
- Light / Dark / System themes  
- Emoji picker & rich interaction support  
- Push notifications for incoming messages  
- One-click join via shareable room links  

⚙️ **Technical Highlights**
- Built as a **lightweight single-page architecture** (no heavy build setup)
- Clean **event-driven socket architecture**
- PWA-ready with service worker support  
- Optimized for **speed, minimal footprint, and instant usability**

🔐 **Planned Enhancements**
- End-to-End Encryption (E2EE) for secure message transmission  
- File & media sharing capabilities  
- Typing indicators and richer real-time signals  

⚡ Focused on delivering **fast, private, and disposable communication without data retention**
